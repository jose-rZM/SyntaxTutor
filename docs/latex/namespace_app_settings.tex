\doxysubsection{Detailed Description}
Where the app keeps its settings. 

The identity is registered once at startup and every QSettings is built from it, so each platform files the settings its own way:
\begin{DoxyItemize}
\item mac\+OS: \texorpdfstring{$\sim$}{\string~}/\+\+Library/\+\+Preferences/\+me.jram.\+Syntax\+Tutor.\+plist (the domain)
\item Windows: HKEY\+\_\+\+CURRENT\+\_\+\+USER\textbackslash{}\+Software\textbackslash{}\+Syntax\+Tutor\textbackslash{}\+Syntax\+Tutor
\item Linux: \texorpdfstring{$\sim$}{\string~}/.config/\+\+Syntax\+Tutor/\+\+Syntax\+Tutor.\+conf 
\end{DoxyItemize}
