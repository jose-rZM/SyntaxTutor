\doxysubsection{Detailed Description}
The application\textquotesingle{}s type scale: every text size on screen, in points. 

Fonts are sized in points so Qt can map them to each platform\textquotesingle{}s logical DPI; nothing here reads the DPI or the device pixel ratio. The user\textquotesingle{}s text size preference (\doxylink{namespace_app_text_scale}{App\+Text\+Scale}) is a plain multiplier on top.

{\ttfamily app.\+qss} never spells a size out. It names a role, as in {\ttfamily font-\/size: \$font-\/body;}, and \doxylink{namespace_app_typography_a8ced112c8886506a81b4028ab9c3df37}{resolve\+Style\+Sheet} substitutes the scaled value when the sheet is loaded. C++ code asks for the same roles through \doxylink{namespace_app_typography_a1d8837f59d9e412638b5a27be675c948}{font} or \doxylink{namespace_app_typography_a5c2b3c26731613ad2991e00358243bfb}{css\+Size}, so both channels share one table.

Paper is a separate domain: the PDF exports keep their own {\ttfamily pt} sizes and never follow the screen preference.

A length that has to hold text, grown to how big text renders here.
