\doxysubsection{Detailed Description}
Main window for the SLR(1) interactive tutoring mode in \doxylink{namespace_syntax_tutor}{Syntax\+Tutor}. 

This class implements an interactive, step-\/by-\/step tutorial to teach students how to construct SLR(1) parsing tables, including closure, GOTO, automaton construction, FOLLOW sets, and the final table.

It supports animated feedback, pedagogical guidance, error correction, and export of the tutoring session.

The tutor follows a finite-\/state flow ({\ttfamily \doxylink{slrtutorwindow_8h_a62d8c04e822006d61f10fc42c058473d}{State\+Slr}}) to structure learning, with corrective explanations and automatic evaluation at each step.
