\doxysubsection{Detailed Description}
The user\textquotesingle{}s text size preference, as a percentage. 

Only the preference lives here: how big each piece of text is comes from the type scale in \doxylink{namespace_app_typography}{App\+Typography}, which multiplies its point sizes by \doxylink{namespace_app_text_scale_a01feb2d6132cdbe0da4069ea092cf050}{factor}. The platform\textquotesingle{}s own point-\/to-\/pixel mapping is left to Qt, so 100\% means "{}as designed"{} on every system rather than a DPI correction.
