\doxysubsection{Detailed Description}
Parses user-\/written grammar text into a \doxylink{struct_grammar}{Grammar} object. 

Input format, kept deliberately flexible:
\begin{DoxyItemize}
\item Each rule is {\ttfamily LHS -\/\texorpdfstring{$>$}{>} SYMBOL SYMBOL ... .} and ends with a dot. Rules may span several lines and several rules may share one line.
\item Symbols are separated by whitespace; any whitespace-\/free string is a valid symbol, so multi-\/character tokens such as {\ttfamily id} or {\ttfamily function} are supported. {\ttfamily A b} is two symbols while {\ttfamily Ab} is one.
\item "{}→"{} is accepted as an alias of "{}-\/$>$"{}, with or without surrounding spaces.
\item Alternatives can be grouped with {\ttfamily \texorpdfstring{$\vert$}{|}}: {\ttfamily A -\/\texorpdfstring{$>$}{>} a \texorpdfstring{$\vert$}{|} b .}
\item An empty right-\/hand side ({\ttfamily A -\/\texorpdfstring{$>$}{>} .} or an empty {\ttfamily \texorpdfstring{$\vert$}{|}} branch) denotes an epsilon production.
\item Non-\/terminals are exactly the symbols that appear on a left-\/hand side; every other symbol is a terminal. The first rule defines the axiom. 
\end{DoxyItemize}
