\doxysubsection{Detailed Description}
A single guided step for constructing the LL(1) table. 

This widget presents one (non-\/terminal, terminal) cell at a time with a compact explanation card and an answer card. The expected answer is the production that belongs in the cell; the input is validated ignoring whitespace so "{}a B"{}, "{}a  B"{} and "{}a\+B"{} are all accepted. It emits a signal whenever the completion state changes.
