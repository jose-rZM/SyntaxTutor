\doxysubsection{Detailed Description}
Interactive assistant that guides the student step-\/by-\/step through the SLR(1) parsing table. 

This dialog presents one cell of the SLR(1) parsing table at a time, asking the user to deduce the correct ACTION or GOTO entry based on the LR(0) automaton and FOLLOW sets. It intentionally avoids the native wizard widget to keep a consistent look across platforms.
