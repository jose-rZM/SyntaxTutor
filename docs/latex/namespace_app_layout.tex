\doxysubsection{Detailed Description}
Layout helpers that keep text from being clipped. 

Qt sizes word-\/wrapped text by height-\/for-\/width, but only some containers honour it. Top-\/level windows and widgets placed directly in a QMain\+Window or a QStacked\+Widget are given the height their layout guesses for an arbitrary width, so a title that wraps to one more line than the guess is cut in half. The effect depends on font, text size and window width, which is why it only shows on some systems.
