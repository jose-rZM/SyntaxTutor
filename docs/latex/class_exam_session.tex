\doxysubsection{Detailed Description}
Accumulates graded answers during an exam-\/mode exercise. 

In exam mode the tutors give no feedback: every answer is recorded here with its real correctness while the exercise advances along the correct path. At the end the session produces the stats and the 0-\/10 grade shown in the exam report.
