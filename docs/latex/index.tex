{\bfseries{An interactive tutor for learning LL(1) and SLR(1) parsing.}}

\href{https://github.com/jose-rZM/SyntaxTutor/releases/latest}{\texttt{}} \href{https://github.com/jose-rZM/SyntaxTutor/actions/workflows/tests.yml}{\texttt{}} \+[](LICENSE) 

\doxylink{namespace_syntax_tutor}{Syntax\+Tutor} helps compiler students understand how LL(1) and SLR(1) parsers are built. The student works through each algorithm one question at a time: FIRST and FOLLOW sets, prediction symbols, LR(0) items, closures, transitions and, finally, the parsing table. Every answer is checked on the spot, and a wrong answer leads to smaller questions that rebuild the reasoning step by step, so the student learns why a result is what it is.

\begin{DoxyNote}{Note}
{\bfseries{Project status.}} \doxylink{namespace_syntax_tutor}{Syntax\+Tutor} 2.\+0 is the final feature release. The project is considered complete, and no further development is planned.
\end{DoxyNote}

\begin{DoxyItemize}
\item {\bfseries{Step-\/by-\/step tutors}} for LL(1) and SLR(1), with immediate feedback on every answer.
\item {\bfseries{Pedagogical branching}}: mistakes open smaller questions instead of revealing the result.
\item {\bfseries{Your own grammars}}: a grammar editor with live validation, or generated grammars at three difficulty levels.
\item {\bfseries{Exam mode}}: no feedback during the exercise, a 0–10 grade at the end and a question-\/by-\/question review.
\item {\bfseries{LR(0) automaton}} drawn progressively as the student computes states and transitions.
\item {\bfseries{Guided table modes}} that walk through the LL(1) and SLR(1) tables one cell at a time.
\item {\bfseries{PDF export}} of the conversation, sets, automaton states, parsing tables and exam reports.
\item {\bfseries{Quick references}} for the theory of both algorithms.
\item {\bfseries{Spanish and English}} interface, adjustable text size and gamified progress.

Once the application is open, the {\bfseries{Tutorial}} button on the home screen gives a short tour of the interface and the first exercises.\hypertarget{index_autotoc_md3}{}\doxysubsection{\texorpdfstring{How it works}{How it works}}\label{index_autotoc_md3}
{\bfseries{LL(1).}} The tutor asks for the size of the predictive table and then, rule by rule, for the prediction symbols. A wrong answer is broken down into the FIRST set of the right-\/hand side and the FOLLOW set of the left-\/hand side before the question is asked again. The exercise ends with the LL(1) table, where wrong cells are highlighted and a guided mode is available.

{\bfseries{SLR(1).}} The tutor starts from the closure of the initial item and builds the LR(0) collection state by state: number of items, symbols after the dot and every transition δ(\+I, X). It then covers the table dimensions, states with complete items, LR(0) conflicts resolved with FOLLOW sets and reduce-\/only states, and ends with the SLR(1) parsing table.\hypertarget{index_autotoc_md4}{}\doxysubsection{\texorpdfstring{Screenshots}{Screenshots}}\label{index_autotoc_md4}

Requirements:


\begin{DoxyItemize}
\item Qt 6, including {\ttfamily qmake6} and the Qt SVG module
\item A C++20 compiler: GCC 11 or newer, a recent Clang, or MSVC 2022
\item \href{https://github.com/google/googletest}{\texttt{Google\+Test}}, only for the backend tests
\end{DoxyItemize}

With GNU make, the repository\textquotesingle{}s {\ttfamily GNUmakefile} builds out of tree:

{\ttfamily make check-\/core} and {\ttfamily make check-\/ui} run each suite on its own; the same tests run in CI on every push and pull request. To use qmake directly, pass {\ttfamily -\/f Makefile}, because GNU make would otherwise pick up the {\ttfamily GNUmakefile}:
