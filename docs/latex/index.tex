   \hypertarget{index_autotoc_md0}{}\doxysection{\texorpdfstring{Syntax\+Tutor: An Interactive Tool for Learning Syntax Analysis}{Syntax\+Tutor: An Interactive Tool for Learning Syntax Analysis}}\label{index_autotoc_md0}
\doxylink{namespace_syntax_tutor}{Syntax\+Tutor} is an educational application designed to help compiler students understand LL(1) and SLR(1) parsing algorithms. Through a visual and interactive interface, it guides users step-\/by-\/step through the computation of FIRST, FOLLOW, CLOSURE, GOTO, predictive parsing tables, and LR automata, offering real-\/time pedagogical feedback.

Rather than acting as a mere calculator, \doxylink{namespace_syntax_tutor}{Syntax\+Tutor} functions as a learning companion. It explains the reasoning behind each step, highlights common mistakes, and encourages students to engage with the theory behind the algorithms.

\hypertarget{index_autotoc_md4}{}\doxysubsection{\texorpdfstring{🎯 Key Features}{🎯 Key Features}}\label{index_autotoc_md4}

\begin{DoxyItemize}
\item {\bfseries{Educational focus}}: built to teach, not just compute. Wrong answers branch into smaller questions instead of revealing the result.
\item {\bfseries{LL(1) and SLR(1) tutors}}: FIRST, FOLLOW and prediction symbols; LR(0) items, closures, transitions and the parsing tables.
\item {\bfseries{Your own grammars}}: type any grammar, with live validation, or practise with generated ones at three difficulty levels.
\item {\bfseries{Exam mode}}: no feedback during the exercise and a 0-\/10 grade with a full question-\/by-\/question review.
\item {\bfseries{LR(0) automaton}}: drawn progressively as you build the states.
\item {\bfseries{Guided table modes}}: fill in the LL(1) and SLR(1) tables one cell at a time, with hints.
\item {\bfseries{PDF export}} of the conversation, sets, automaton states, tables and exam reports.
\item {\bfseries{Spanish and English}}, adjustable text size and gamified progress.
\end{DoxyItemize}

 To use qmake directly instead, pass {\ttfamily -\/f Makefile}: in the repository root GNU make would otherwise pick up the {\ttfamily GNUmakefile} above.
