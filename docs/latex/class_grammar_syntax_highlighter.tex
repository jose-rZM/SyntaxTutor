\doxysubsection{Detailed Description}
Lightweight highlighter for user-\/written grammar text. 

Colors the structural pieces of a grammar (arrows, rule dots and alternative pipes) and renders the currently-\/detected non-\/terminals in the accent color, so the user gets immediate feedback on how their text is being interpreted.
