\doxysubsection{Detailed Description}
Describes one problem found while parsing user-\/written grammar text. 

Errors carry a machine-\/readable kind, the 1-\/based line where the offending rule starts, and the offending fragment so the GUI can build a localized, user-\/friendly message.
