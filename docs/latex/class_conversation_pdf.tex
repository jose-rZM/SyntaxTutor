\doxysubsection{Detailed Description}
Builds the PDF of an LL(1) or SLR(1) session. 

Both tutors describe their exercise -\/ grammar, conversation, sets, table, or the graded review of an exam -\/ and this class lays it out the same way. It only uses the subset of HTML and CSS that QText\+Document supports when printing (tables, backgrounds, fonts), and splits tables too wide for an A4 page into blocks of columns, so grammars typed by the user, however large, stay readable.
