\doxysubsection{Detailed Description}
End-\/of-\/exam report: grade, stats and a question-\/by-\/question review. 

Shown when an exam-\/mode exercise finishes. The headline is the 0-\/10 grade; below it a review lists every graded item with the student\textquotesingle{}s answer and the expected one, like a corrected exam sheet. The full report can be exported to PDF through the owning tutor window.
