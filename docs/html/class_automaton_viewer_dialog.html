Detailed Description

Non-modal floating window that hosts the LR(0) automaton view.

The dialog is a thin shell: it embeds an externally-owned AutomatonView (so its progressive reveal state is preserved across open/close cycles) and adds a toolbar with zoom in/out, fit-to-view and center-current actions. It never owns the view: on destruction it reparents the view out so the tutor can keep reusing it. Being non-modal, the student can keep it open while continuing the exercise.
