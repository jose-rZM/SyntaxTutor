Detailed Description

Outcome of parsing user-written grammar text.

When errors is empty, grammar holds a fully-built grammar: symbols are classified (non-terminals are exactly the left-hand sides), the axiom is the left-hand side of the first rule, and the grammar has been augmented with a fresh axiom rule X -> <axiom> $ following the app-wide convention.
