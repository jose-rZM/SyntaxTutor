Detailed Description

Dialog where the user writes their own grammar for an exercise.

The user types rules in the LHS -> SYMBOL ... . format. The text is parsed and validated live: format errors are reported with line numbers, the detected axiom / non-terminals / terminals are summarized, and the grammar is checked to be LL(1) or SLR(1) depending on the exercise the dialog was opened for. The last accepted grammar is persisted through QSettings so it can be practiced again.
