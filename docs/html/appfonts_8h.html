QFont appMonospaceFont ( )
inline

Application-wide monospace font.

macOS keeps the native fixed font (Menlo); Windows and Linux use the bundled JetBrains Mono, loaded in main(), because their system fixed fonts (Courier New, distro-dependent) degrade the visuals.
