Detailed Description

The user's text size preference, as a percentage.

Only the preference lives here: how big each piece of text is comes from the type scale in AppTypography, which multiplies its point sizes by factor. The platform's own point-to-pixel mapping is left to Qt, so 100% means "as designed" on every system rather than a DPI correction.
