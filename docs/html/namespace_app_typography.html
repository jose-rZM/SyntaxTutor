Detailed Description

The application's type scale: every text size on screen, in points.

Fonts are sized in points so Qt can map them to each platform's logical DPI; nothing here reads the DPI or the device pixel ratio. The user's text size preference (AppTextScale) is a plain multiplier on top.

app.qss never spells a size out. It names a role, as in font-size: $font-body;, and resolveStyleSheet substitutes the scaled value when the sheet is loaded. C++ code asks for the same roles through font or cssSize, so both channels share one table.

Paper is a separate domain: the PDF exports keep their own pt sizes and never follow the screen preference.

◆ lengthForText()

int AppTypography::lengthForText ( int designPx)
inline

A length that has to hold text, grown to how big text renders here.

designPx is the length the layout was drawn with, when body text was Role::Body points - that is, as many pixels - high. It grows in step with the body font as it actually renders, which covers both the user's text scale and the platform's point-to-pixel mapping. Use it for fixed or minimum sizes of things that contain text; leave decoration in plain logical pixels.
