◆ setAutoGrowLines()

void CustomTextEdit::setAutoGrowLines ( int minLines,
int maxLines )

Makes the height follow the content, animated, between minLines and maxLines lines of text. Content beyond that scrolls.

The bounds are measured from the widget's own font and style, so they stay right at any text size and on any platform.
