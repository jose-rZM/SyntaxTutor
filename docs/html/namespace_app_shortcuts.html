QString AppShortcuts::primaryModifierName ( )
inline

Name of the key behind Qt::ControlModifier on this platform.

On macOS Qt maps ControlModifier to the Command key, so a shortcut written for Ctrl is pressed with Cmd there. Use this in any text that names that key, so it matches what the user actually presses.
