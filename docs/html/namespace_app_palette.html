void AppPalette::apply ( )
inline

Palette entries the theme needs that app.qss cannot set.

Links in rich text (QLabel, QTextBrowser) take their colour from the palette; a style sheet rule on a has no effect. The platform's light palette makes them dark blue, barely readable on this dark theme - which is what Linux showed, while macOS hid it with a dark palette of its own.
